SupportedPixelFormats

Gets the list of PixelFormats that can be used when creating a document with CreateDocument(SizeInt32, in PixelFormat).

IReadOnlyList<PixelFormat> SupportedPixelFormats { get; }

Property Value

IReadOnlyList<PixelFormat>

Remarks

This is the current list of supported pixel formats:

  • Bgr24
  • Bgr32
  • Bgr48
  • Bgra32
  • Bgra64
  • Pbgra32
  • Pbgra64
  • Prgba32
  • Prgba64
  • Prgba64Half
  • Prgba128Float
  • Rgb24
  • Rgb32
  • Rgb48
  • Rgb48Half
  • Rgb64
  • Rgb64Half
  • Rgb96Float
  • Rgb128Float
  • Rgba32
  • Rgba64
  • Rgba64Half
  • Rgba128Float
  • Cmyk32
  • Cmyka40
  • Cmyk64
  • Cmyka80

Pixel formats will only ever be added to this list in future versions; they will never be removed. You can rely on the fact that if a pixel format is in this list in version X, it will be there in version X+1.

For documents that use pixel formats that are not in the NativePixelFormats list, they will be automatically converted to use a native pixel format as part of the loading process.
