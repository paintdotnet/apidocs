Properties

NativePixelFormats

Gets the list of PixelFormats supported natively by Paint.NET. A document created in one of these pixel formats will not need to be converted after being returned from Load. This improves performance, reduces temporary memory usage, and ensures preservation of exact color values.

SupportedPixelFormats

Gets the list of PixelFormats that can be used when creating a document with CreateDocument(SizeInt32, in PixelFormat).
