Properties

AlphaMode

Specifies the alpha mode for the input, and for the output. The default value is Premultiplied.

Angle

Specifies the angle of the screen, in degrees. The default value is 0. In Cmyk the four inks sit at the traditional 15, 75, 0 and 45 degrees, and this turns all of them together: it rotates the whole rosette while leaving the relationships between the screens intact. In Monochrome it turns the single screen, which sits on black's 45.

BlackGeneration

Specifies how much of the ink that could go into black actually does. At 1 every bit of neutral ink is carried by the black screen; at 0 it is built out of cyan, magenta and yellow together. The range is [0, 1], the default is 0.75. Ignored when ColorMode is set to Monochrome. Tone-neutral by construction, but it decides whether the result reads as a rosette - at 1 the chromatic screens carry nothing neutral and there is none - and it costs accuracy in the deep shadows, where near-closed shapes leave a sliver at each cell corner whose rendered area depends on the screen's angle.

CellSize

Specifies the screen ruling, in pixels: the distance from one cell to the next. The range is [2, 200], the default is 8.

ColorMode

Specifies whether the image is separated into four process-color inks on four grids, or screened with a single black ink on one. The default value is Cmyk.

GridOrigin

Specifies the point, in the input's own coordinate space, that every screen puts a cell centre exactly on. The default value is { 0, 0 }, but usually this is set to the center point of the image or selected area.

Input
InputColorContext

Specifies the color context of the Input image, which is used to optimize the quality of this effect's rendering.

Pattern

Specifies the shape that is laid down in each cell of the screen. The default value is Dots.

Quality

Specifies how many jittered samples of the screen each output pixel averages: the square of this value. The range is [1, 8], the default is 2. The shapes are rendered with hard edges, so this controls antialiasing. A value of 1 produces aliased output.

Softness

Specifies how soft the edge of each shape is. At 0 there is no transition beyond what Quality antialiases; at 1 it grows with CellSize, dissolving the shapes into soft blobs at any ruling. The range is [0, 1], the default is 0.
