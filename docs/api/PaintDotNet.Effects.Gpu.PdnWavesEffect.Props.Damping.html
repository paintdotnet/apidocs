Damping

The percentage of the wave's amplitude that is lost over each successive wavelength of distance from Center. At 50, for example, each ring of the wave is half as strong as the one before it. Zero disables damping.
The range is [0, 100] and the default value is 0.

public DynamicImage.ValuePropertyAccessor<float> Damping { get; }

DynamicImage.ValuePropertyAccessor<float>

Remarks

Only the patterns whose phase is a distance out from Center can attenuate over it: Radial, Tangential, SquareRings, DiamondRings, Spiral, and FromEdges. The linear patterns measure a signed distance and Angular's phase wraps around, so damping those would amplify half the image rather than attenuate it. They ignore this instead.
