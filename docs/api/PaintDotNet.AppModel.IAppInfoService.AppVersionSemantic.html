AppVersionSemantic

Gets the app version as a semantic version string which can be parsed using the NuGet.Versioning package.

string AppVersionSemantic { get; }

Property Value

string

Remarks

        Examples of semantic versions include:

  • 5.2.1, which is a stable version
  • 5.2.1-beta.5.201.9810.31466, which is a pre-release version
        Note that pre-release versions have a dash (<code>'-'</code>) character in them, while stable versions do not.
        You can also use the <xref href="PaintDotNet.AppModel.AppInfoServiceExtensions.get_IsStableVersion(PaintDotNet.AppModel.IAppInfoService)" data-throw-if-not-resolved="false"></xref> extension property.


        See <a href="https://semver.org"></a> for more info.
