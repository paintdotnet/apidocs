RecommendedColorSpace

Gets the KnownColorSpace whose gamut best accommodates the given CICP color information, for use as a working or destination color space.

public KnownColorSpace RecommendedColorSpace { get; }

Property Value

KnownColorSpace

Remarks

When CanColorTransformFrom is true, but CanCreateColorContext is false, you can use this property to create an IColorContext to use with CreateColorTransformer(IBitmapSource, CicpColorSpace, IColorContext, in PixelFormat) or CreateColorTransformedBitmap(IImagingFactory, IBitmapSource, CicpColorSpace, IColorContext, in PixelFormat).

The recommendation is driven solely by the color primaries, which determine the gamut; the transfer characteristics and range do not affect it, as those concern luminance encoding rather than gamut. Primaries that are not recognized (including Unspecified) fall back to Srgb.
