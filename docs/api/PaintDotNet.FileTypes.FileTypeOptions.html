Contains options and configuration settings for a FileType implementation. Instances of this class are created by FileType plugins and passed to the base constructor. This information is then available through the Info property.

Remarks

Use the FileTypeOptions.Create() method and C# with syntax to create instances of this class. For example: 

public sealed class MyFileType
    : FileType
{
    public MyFileType(IFileTypeHost host)
        : base(
            host,
            "My FileType Plugin",
            FileTypeOptions.Create() with
            {
                SaveExtensions = [".myftp"],
                LoadExtensions = [".myftp"],
                IsSavingConfigurable = true
            })
    {
    }
}
