The luminance statistics of a linear HDR image needed to tone-map it, in nits (cd/m²). Produced by Gather(IBitmapSource<ColorRgba128Float>, double, float, bool), which measures the pixels, or by FromNits(float) from known metadata such as a MaxCLL value.

Properties

MaximumNits

The absolute maximum per-pixel max(r, g, b) value across the image, in nits (cd/m²).

PeakNits

The peak (high-percentile) per-pixel max(r, g, b) value, in nits (cd/m²). This is the content peak used as the roll-off knee: content at this level maps to SDR white, and the small fraction of pixels above it is clipped.

Methods

FromNits(float)

Creates statistics from a content maximum luminance expressed in nits, such as the MaxCLL value from an image's HDR metadata. Both PeakNits and MaximumNits are set to it.

Gather(IBitmapSource<ColorRgba128Float>, double, float, bool)

Scans source in a single pass to gather the luminance statistics needed to tone-map it. The image is measured in horizontal bands; the per-band measurement work is spread across threads, while reads from source are governed by allowMultithreadedCopyPixels.
