Properties

AlphaThreshold

When PixelFormat is set to Indexed8, pixels with an alpha value below this value will be considered transparent.

The default value is 128.

DitherLevel

When PixelFormat is set to an indexed pixel format (Indexed8 or lower), this configures the amount of dithering.

The range of this property is [0, 8]. The default value is 7.

Interlaced

Gets or sets whether the PNG should be saved with interlacing. This does not affect how the image appears once it has been loaded, but it may improve how it looks while it is loading on a slow network or Internet connection.

The default value is false.

PixelFormat

Gets or sets the pixel format and bit-depth to save the PNG at. The default value is AutoDetect, which chooses the PngPixelFormat that produces the smallest file size without losing any information.

QuantizationAlgorithm

When PixelFormat is set to an indexed pixel format (Indexed8 or lower), this configures which quantization algorithm is used.

The default value is Octree.
