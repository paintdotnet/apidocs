CreateColorTransformer(IBitmapSource, CicpColorSpace, IColorContext, in PixelFormat)

Color-transforms source, whose colorimetry is described by sourceCicpColorSpace, into the given destination color context and pixel format.

public static IBitmapSource CreateColorTransformer(this IBitmapSource source, CicpColorSpace sourceCicpColorSpace, IColorContext dstColorContext, in PixelFormat dstFormat)

Parameters

source IBitmapSource
sourceCicpColorSpace CicpColorSpace
dstColorContext IColorContext
dstFormat PixelFormat

Returns

IBitmapSource

The transformed bitmap, in the destination color context and pixel format (owned by the caller).

Remarks

CICP transfers that can be expressed as an ICC profile are transformed directly from that synthesized profile. PQ and HLG cannot, so they are first decoded to linear light by a dedicated kernel that tags the result with a known linear profile, and the transform proceeds from there. Any other transfer that is neither ICC-representable nor PQ/HLG is unsupported.

Exceptions

ArgumentException

Thrown if the CICP color information cannot be honored (e.g. non-RGB matrix coefficients or unrepresentable primaries or transfer). The message describes why.
