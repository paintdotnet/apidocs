IsSavingConfigurable

Indicates whether saving can be configured through the use of IFileTypeSaveOptions and IFileTypeSaveOptionsControl.

LoadExtensions

Gets the list of file extensions that the FileType can load. These will be prefixed with a dot, e.g. { ".xyz", ".ywx", ".wyx" }

SaveExtensions

Gets the list of file extensions that the FileType can save. These will be prefixed with a dot, e.g. { ".xyz", ".ywx", ".wyx" }

SupportsCancellationExceptions

If true, then the Stream and/or ProgressEventHandler may throw an OperationCanceledException so as to cancel the save/load operation. This is usually encountered when the user is working with the Save Options dialog, or if they press the Cancel button while loading.

SupportsSavingLayers

Indicates whether the FileType supports saving layers. This affects whether the image is flattened before being sent to the FileType's Save() method.
