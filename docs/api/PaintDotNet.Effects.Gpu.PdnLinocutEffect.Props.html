Properties

AlphaMode

Specifies the alpha mode for the input and output. The default value is Premultiplied.

Contrast

Specifies how steeply the line width responds to tone around mid grey. The range is [0.25, 4] and the default value is 1, which is an identity.

Gamma

Specifies the exponent applied to the ink demand. The range is [0.25, 4] and the default value is 1, which is an identity.

InkColor

Specifies the color of the ink, in the same color space this effect renders in. The default value is black (R=G=B=0).

Input
InputColorContext

Specifies the color context of the Input image, as well as the InkColor and PaperColor properties. This is used to optimize the quality of this effect's rendering.

LineAngle

Specifies the angle of the lines, in degrees counter-clockwise. The range is [0, 360] and the default value is 45. In Contour this is the direction the lines fall back to where the image is flat; in CrossHatch it is the first of the two trains, and the second sits ninety degrees away from it.

LineMode

Specifies how the train of lines is oriented. The default value is Parallel.

LineSpacing

Specifies the distance, in pixels, from one line to the next. The range is [2, 64] and the default value is 8.

PaperColor

Specifies the color of the paper, in the same space this effect renders in. The default is white (R=G=B=1).

Roughness

Specifies how much the lines wander away from a perfect ruling, so that they read as cut by hand rather than drawn by a machine. The range is [0, 1] and the default value is 0.2.

Seed

Specifies the seed that the randomized roughness is generated from. The default value is 0.
