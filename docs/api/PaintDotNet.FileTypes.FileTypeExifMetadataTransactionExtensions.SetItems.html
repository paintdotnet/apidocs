Parameters

exifTx IFileTypeExifMetadataTransaction

The EXIF metadata transaction.

items IEnumerable<KeyValuePair<ExifPropertyKey, ExifValue>>

The key-value pairs that define the property items to set.

Remarks

If a property item already exists for any of the given paths, they will be overwritten. If the same path is encountered multiple times in the list of path-value pairs, every value will be used when writing out the corresponding metadata.
