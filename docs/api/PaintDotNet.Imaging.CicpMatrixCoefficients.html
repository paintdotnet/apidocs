Identifies the matrix coefficients used to derive luma and chroma signals from the source RGB primaries. These are the "MatrixCoefficients" code points defined by ITU-T H.273 (Table 4) and used by the PNG cICP chunk.

public enum CicpMatrixCoefficients : byte

Remarks

The underlying type is byte to match the 8-bit code point in the cICP chunk. Only the values defined by H.273 are named here; reserved and unassigned values (3 and 15–255) are intentionally not enumerated, but still round-trip faithfully because the storage type is a raw byte.

For PNG, the only valid value is Identity, because PNG stores RGB (not Y'CbCr) samples. Other values are retained for faithful round-tripping and validation.
