Properties

AlphaMode

Specifies the alpha mode for the input and output. The default value is Premultiplied.

BackgroundColor

The ground the dots are laid down on. The default value is opaque white.

CellFill

Specifies how much of its cell each dot fills, as a fraction of the cell size: at 1 a dot's diameter equals CellSize and neighboring dots' edges just meet, and at 2 it is twice that and they overlap heavily. The range is [0.1, 2] and the default is 1.41, which causes the dots edges to touch.

CellSize

Specifies the size of a cell, in pixels: the source is divided into a square lattice this far apart and one dot is laid down per cell. The range is [3, 64] and the default is 12.

Center

The point the dot lattice is anchored at, in pixels: growing CellSize scales the lattice out from here. This is usually set to the image or selection center so that enlarging the cells is perceived as a zoom into the middle rather than out of the top-left corner. The default is (0, 0), the top-left corner.

ColorJitter

Specifies how far each dot's own hue and chroma are allowed to wander from the color it sampled. The range is [0, 1], where 1 is a shift of up to 30 degrees of CIE hue and up to 30 of CIE chroma, and the default is 0.25.

Input
InputColorContext

Specifies the color context of the Input image, as well as the BackgroundColor property. This is used to optimize the quality of this effect's rendering.

PlacementJitter

Specifies how far a dot's center can be randomly displaced from the center of its own cell, as a fraction of the distance at which it would reach the cell's wall. The range is [0, 1] and the default is 1.0.

Seed

Specifies the seed that the randomized lattice jitter and the per-dot color jitter are generated with. The default value is 0.

ToneResponse

Specifies how strongly a dot's size follows the tone of the image underneath it: at 0 every dot is the full CellFill, and at 1 a dot in a light, neutral area shrinks to a quarter of that. The range is [0, 1] and the default is 1.0.
