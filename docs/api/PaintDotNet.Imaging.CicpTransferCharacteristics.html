Identifies the opto-electronic / electro-optical transfer characteristic (the "gamma" or EOTF) of the source. These are the "TransferCharacteristics" code points defined by ITU-T H.273 (Table 3) and used by the PNG cICP chunk.

public enum CicpTransferCharacteristics : byte

Remarks

The underlying type is byte to match the 8-bit code point in the cICP chunk. Only the values defined by H.273 are named here; reserved and unassigned values (0, 3, and 19–255) are intentionally not enumerated, but still round-trip faithfully because the storage type is a raw byte.
