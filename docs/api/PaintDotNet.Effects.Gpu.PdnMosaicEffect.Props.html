Properties

AlphaMode

Specifies the alpha mode for the input and output. The default value is Premultiplied.

BevelDepth

Specifies how strongly each tile is raised away from its edges. The range is [0, 1] and the default value is 0.2.

Center

The point the tile lattice is anchored at, in pixels: growing TileSize scales the lattice out from here. A caller sets this to the image center so that enlarging the tiles reads as a zoom into the middle rather than out of the top-left corner. The default is (0, 0), the top-left corner.

GroutColor

Specifies the color of the grout. The default value is [R=G=B=0.5].

GroutWidth

Specifies how wide a line of grout is, as a fraction of the tile size. The range is [0, 0.5] and the default value is 0.04.

Input
InputColorContext

Specifies the color context of the Input image, as well as the GroutColor property. This is used to optimize the quality of this effect's rendering.

LightAngle

Specifies the direction the light comes from, in degrees, measured counterclockwise from the right. The range is [0, 360) and the default value is 135.

LightnessJitter

Specifies how much the tiles vary in lightness from one to the next. The range is [0, 1] and the default value is 0.15.

PositionJitter

Specifies how far each tile's sampling point is moved away from the tile's center, as a fraction of the tile size. The range is [0, 0.5] and the default value is 0.1.

Seed

Specifies the seed that the per-tile random values are generated from. The default value is 0.

TileColorMode

Specifies how each tile's single flat color is chosen from the pixels it covers. The default value is Average.

TileShape

Specifies the shape of the tiles. The default value is Square.

TileSize

Specifies the size of a tile, in pixels: the distance across a tile from one flat side to the opposite one for most shapes, the length of a side for triangles, and the short side of a brick for the brick, basketweave, and herringbone shapes. The range is [4, 200] and the default value is 24.
