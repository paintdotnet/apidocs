FileTypeSaveOptions

The base class for IFileTypeSaveOptions implementations. These are created by FileTypes that support configurable saving, and are returned by their OnCreateDefaultSaveOptions() implementation.

FileTypeSaveOptionsControl

The base class for IFileTypeSaveOptionsControl implementations. These must be provided by FileTypes that support configurable saving. Most FileType plugins will be PropertyBasedFileTypes and will not need to implement this class.

IFileTypeSaveOptions

Represents the options used when saving with a FileTypeSaver. This interface is implemented by creating a class that derives from FileTypeSaveOptions, which is then returned by OnCreateDefaultSaveOptions(). The FileType must have also provided a FileTypeOptions to its base constructor with IsSavingConfigurable set to true.

IFileTypeSaveOptionsControl

This interface is implemented by FileTypeSaveOptionsControl, which is used to implement a custom Save Options UI for a FileType. The control is then returned by OnCreateSaveOptionsControl(). The FileType must have also provided a FileTypeOptions to its base constructor with IsSavingConfigurable set to true.
