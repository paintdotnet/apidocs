Indicates the black level and range of the luma and chroma signals. This is the "VideoFullRangeFlag" defined by ITU-T H.273 and used by the PNG cICP chunk.

public enum CicpVideoFullRangeFlag : byte

Fields

Narrow = 0

Narrow ("limited" or "studio swing") range. The signal does not occupy the full numeric range of the encoding (e.g. 16–235 for 8-bit luma).

Full = 1

Full range. The signal occupies the full numeric range of the encoding. This is the only value permitted in a PNG cICP chunk.

Remarks

The underlying type is byte to match the 8-bit code point in the cICP chunk. For PNG, the only valid value is Full. The value is retained for faithful round-tripping and validation.
