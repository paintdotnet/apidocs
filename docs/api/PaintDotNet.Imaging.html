CicpColorPrimaries

Identifies the chromaticity coordinates of the source primaries (red, green, blue) and the white point. These are the "ColourPrimaries" code points defined by ITU-T H.273 (Table 2) and used by the PNG cICP chunk.

CicpMatrixCoefficients

Identifies the matrix coefficients used to derive luma and chroma signals from the source RGB primaries. These are the "MatrixCoefficients" code points defined by ITU-T H.273 (Table 4) and used by the PNG cICP chunk.

CicpTransferCharacteristics

Identifies the opto-electronic / electro-optical transfer characteristic (the "gamma" or EOTF) of the source. These are the "TransferCharacteristics" code points defined by ITU-T H.273 (Table 3) and used by the PNG cICP chunk.

CicpVideoFullRangeFlag

Indicates the black level and range of the luma and chroma signals. This is the "VideoFullRangeFlag" defined by ITU-T H.273 and used by the PNG cICP chunk.
