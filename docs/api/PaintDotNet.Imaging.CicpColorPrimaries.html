Enum CicpColorPrimaries

Namespace

Identifies the chromaticity coordinates of the source primaries (red, green, blue) and the white point. These are the "ColourPrimaries" code points defined by ITU-T H.273 (Table 2) and used by the PNG cICP chunk.

Remarks

The underlying type is byte to match the 8-bit code point in the cICP chunk. Only the values defined by H.273 are named here; reserved and unassigned values (0, 3, 13–21, and 23–255) are intentionally not enumerated, but still round-trip faithfully because the storage type is a raw byte.
